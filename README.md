# HMS (Hotel Management System)

Java 기반의 호텔 관리 시스템으로, 대학 팀 프로젝트로 개발되었습니다.

객실, 예약, 고객, 식음료, 결제 및 사용자 관리 기능을 제공하는 데스크톱 애플리케이션입니다.

## 기술 스택

- **Language:** Java 21
- **GUI:** Java Swing, FlatLaf
- **Backend:** Java HTTP Server
- **Data Storage:** JSON
- **Build Tool:** Maven

## 프로젝트 구조

- `backend/` - HTTP API 서버 및 데이터 관리
- `frontend/` - Swing 기반 데스크톱 클라이언트

---

> [!NOTE]
> 본 프로젝트는 대학 팀 프로젝트로 진행되었으며, 현재 개발 및 유지보수가 종료된 상태입니다.
